# About project

***

TaskCLI — это простой менеджер задач, который работает прямо в терминале. Он позволяет управлять делами без лишних окон и мыши, только с клавиатуры.

## Functions

Что умеет TaskCLI? Вы можете добавлять, редактировать и удалять задачи, просматривать их список, отмечать выполненные, назначать приоритеты, добавлять категории и теги, а также фильтровать и искать нужные записи. Все данные хранятся в локальном JSON-файле или, при желании, в SQLite.

### Installation

Установить TaskCLI можно двумя способами. Самый простой — через npm: выполните в терминале команду `npm install -g taskcli`. Если вы хотите собрать программу из исходников, скачайте репозиторий с GitHub, перейдите в папку проекта, установите зависимости командой npm install, затем соберите проект `npm run build` и выполните `npm link`. Для работы потребуется Node.js версии 14 или выше и терминал с поддержкой Unicode.

1. *Download*
2. **Install**
3. ***use***

## Used for

После установки в вашем распоряжении появляется команда task. Вот несколько примеров её использования:

* task add "Купить молоко" — добавить новую задачу.

* task list — показать все задачи.

* task done 3 — отметить задачу с номером 3 как выполненную.

* task delete 5 — удалить задачу под номером 5.

* task tag 2 work — добавить задаче 2 тег work.

* task search отчёт — найти все задачи, в тексте которых встречается слово «отчёт».

### Other

Вы также можете указывать приоритеты, например: task add "Написать отчёт" --priority high. В ответ программа сообщит, что задача добавлена, и покажет её идентификатор. Команда task list выведет таблицу с номерами задач, их описанием, статусом (сделано или нет), приоритетом и тегами. А чтобы увидеть только выполненные задачи, наберите task list --filter "done".
